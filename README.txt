SHIVRAJ MEDICAL - DESKTOP VERSION
=================================
ONE-TIME SETUP ON YOUR WINDOWS PC
1. Install Node.js (LTS) from https://nodejs.org  (just click Next, Next).
2. Double-click  Build-Installer.bat
3. When it finishes, open the "dist" folder and run  "Shivraj Medical Setup 1.0.0.exe"
4. Use the Desktop icon "Shivraj Medical" from now on.

To just test without installing: double-click Run-Without-Installing.bat

FIRST START
- The program asks if you have old data. Choose "Import old data" and select your old
  folder (the one with Shivraj_Data.json). Old files are copied, never changed.
- New data folder: Documents\ShivrajMedicalData
  (Shivraj_Data.json, Backups, Snapshots, Exports) - same as before.
- Use the "Data folder" button to open it. Copy it to a pendrive now and then.
